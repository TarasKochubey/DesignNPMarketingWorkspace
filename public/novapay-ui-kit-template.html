📖 Як використовувати цей шаблон у Figma

1️⃣ Імпортуйте кольори

Завантажте файл novapay-ui-kit-colors.csv і використайте плагін "Variables Importer" або створіть змінні вручну згідно з палітрою вище.

2️⃣ Зробіть скріншоти компонентів

Відкрийте цей HTML файл у браузері, зробіть скріншоти окремих секцій (кнопки, інпути, картки) та імпортуйте їх у Figma як референси при створенні компонентів.

3️⃣ Створіть компоненти з Variants

Використовуйте Auto Layout і створіть варіанти для кожного компонента (Primary/Secondary, Default/Hover/Disabled). Застосовуйте створені Color Variables.

4️⃣ Відкрийте інтерактивний UI Kit

У додатку перейдіть на сторінку /dev-ui-kit для копіювання Tailwind класів та детальних специфікацій.
